# 新概念记录模板

[概念目录](README.md)

- 名称 / 英文 / 别名：
- 所属层级：
- 原始问题：
- 状态：已提及 / 已解释 / 能复述或手算 / 有实验验证
- 首次记录 / 最近更新：
- 适用语境：数学概念 / 特定算子接口 / 固定版本源码 / 设计建议

## 一句话

用一句话说明它是什么、解决什么问题。

## 最小例子

给一个 shape、算式、地址推导或短代码。在代码原位加注释，明确教学假设。

## 与已有概念的关系

| 已有概念 | 关系类型 | 具体关系 |

## 容易混淆的地方

注明相同缩写的不同语境、逻辑形状与物理布局、数学与实现的边界。

## 来源与验证

记录来源文件/网页、源码 commit、实际做过的验证，以及尚未确认的问题。
